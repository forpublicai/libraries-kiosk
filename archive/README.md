# Archived kiosk interface

This folder holds the **previous** front-end for the Public AI Libraries Project —
the Mondrian-style grid of AI tools that served as the kiosk launcher, plus its
About / FAQ / Feature-request pages.

It has been superseded by the new marketing & pilot-recruitment landing page at the
repository root (`/index.html`, `/landing.css`, `/landing.js`).

The pages here are kept intact for reference and still render on their own — relative
asset paths were rewritten to point up one level at the shared `/assets` and
`/favicon.ico` at the repo root. Open `archive/index.html` to view the old interface.

Shared, still-in-use assets (`/assets`, `/extensions`, `/feature-api`) were intentionally
left at the repo root and are **not** part of this archive.
